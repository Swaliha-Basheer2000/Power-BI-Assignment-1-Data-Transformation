# Power-BI-Assignment-1-Data-Transformation
E-Commerce Sales Analysis
This project focuses on preparing and organizing e-commerce sales data in Power BI using Power Query.
Work Completed
- Imported the three provided datasets.
- Performed data cleaning and transformation.
- Created Location, Profit Margin, and Profit Status columns.
- Merged tables using Order ID.
- Checked for missing and duplicate data.
- Applied sorting and filtering.
- Used Group By for data aggregation.
- Established relationships between the tables using Order ID and Category.
